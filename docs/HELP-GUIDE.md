# Finding help in LOOK

Use `lk --help` for the starter map, `lk commands` for a searchable command index,
and `lk doc`, `lk help all`, or `man lk` for the complete offline reference.

For a specific command, use either spelling:

```sh
lk fabric --help
lk help fabric
lk media --help
lk mp --help
lk models --help
lk settings --help
lkn --help
lk notes --help
lo --help
```

Help prints and exits before contacting services, opening an app, or changing a
setting. It lists command forms, recognized flags, and relevant interface keys.
Native argparse commands such as notes and ytd retain their detailed help.
For the node executable itself, `fcl-node --help` lists its flags.

The navigation shortcuts also accept `--help`: `l --help` shows the starter map,
while `ll --help`, `lt --help`, and the corresponding long forms show their
view's help. `lkn --help` forwards to `lk notes --help`.

Notebook has **H / ?** in-app help. Existing Future Crash help uses **H / ?**
from its ambient interface. Simple playback views retain their compact key
footers; `lk mp --help` and `lk media --help` provide expanded guidance.

Future Crash Escape: from Ask, answer, or workstation, return to ambient;
from ambient, open the real shell. `exit` or Ctrl-D in that shell returns to
Future Crash. **Q** in ambient/answer requests an orderly quit. In a workstation
text field, q/Q are ordinary text. Leaving a view does not erase its conversation.

Command help and the full reference are generated by `tools/command_reference.py`
from the live registry, dispatcher, usage strings, and parsers. Install them
with the code so help stays aligned with the running release.
